# 🔐 Python Password Strength Checker

A Python-based password security analysis tool that evaluates password strength, detects common weaknesses, generates secure passwords, and provides security recommendations.

---

## 🚀 Features

- Password length validation
- Uppercase and lowercase detection
- Digit detection
- Special character detection
- Password scoring
- Password strength classification
- Common password detection
- Repeated character detection
- Sequential character detection
- Security recommendations
- Secure password generation
- Interactive command-line interface
